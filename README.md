# Syed Sajjad Uddin

Software engineer in Karachi. I build frontends from an empty repo to production.

Most projects reach me before there is any code. A client in the US or UK has Figma designs and a deadline, and I set up the base everything else sits on: TypeScript and ESLint config, folder structure, shared components, and one API layer the whole app goes through. Then I build the product on top of it.

The other half of my work is making AI coding agents useful on a real codebase — project rules and skills they have to follow, and review of what they generate against the same standards as human code.

Frontend is React, Next.js and TypeScript. TanStack Query and Axios for server state, React Hook Form for forms, Tailwind and shadcn/ui for UI.
